COORDI

今日の気分や好みに合わせて、服装選びをもっと楽しく

このアプリを作った理由

毎朝、何を着ていくか迷うことはありませんか？

気温や季節、出かける場所によって着たい服や適した服装は変わります。 そこでいくつかの項目を選ぶだけでコーディネートのヒントが見つかるアプリ「COORDI」を作りました。 服装を決める時間を少しでも楽しくし、自分では思いつかなかった組み合わせに出会えるかもしれません。

「何を着よう？」を
「これを着て出かけよう！」にする

アプリの使い方

画面の項目を選択して、ボタンを押すとおすすめの服装が表示されます。

01

条件を選ぶ

季節・気温・系統・好きな色・出かける場面を選択します

02

提案ボタンを押す

選んだ条件をもとにプログラムが服装を組み合わせます

03

結果を確認する

トップスやパンツ、靴などの提案を確認します

コーディネートを提案

下の項目を選んで、提案ボタンを押してください。

プログラムで使った仕組み

仕組み 意味・役割 COORDIでの使い方
if 最初の条件を確認する どの季節かを確認し、春なら薄手のシャツを選ぶ
elif 前の条件に当てはまらなかった場合、別の条件を確認する 春ではなかった場合に夏や秋かどうかを確認する
else どの条件にも当てはまらなかった場合に実行する 春・夏・秋のどれでもなければ冬の服装を選ぶ
function 処理をひとまとめにして、必要なときに呼び出して実行する コーディネートを提案する処理をまとめる
def Pythonで関数を定義するときに使う命令 今回は服装なのでdef recommend_outfit と書く。普段はdefの後ろに関数が来る

Pythonプログラムのコード

# COORDI：コーディネート提案プログラム
# 季節・系統・好きな色から服装を提案する

def recommend_outfit(season, style, color):

# 季節に合わせて基本の服装を決める
if season == "春":
top = "薄手のシャツ"
bottom = "デニムパンツ"
elif season == "夏":
top = "半袖Tシャツ"
bottom = "ワイドパンツ"
elif season == "秋":
top = "スウェット"
bottom = "チノパン"
else:
top = "ニットやパーカー"
bottom = "暖かいデニムパンツ"

# 系統に合わせて服装を変更する
if style == "きれいめ":
top = "シンプルなシャツ"
bottom = "スラックス"
elif style == "ストリート":
top = "オーバーサイズのパーカー"
bottom = "ワイドデニム"
elif style == "シンプル":
top = "無地のトップス"

# 選んだ条件とおすすめの服装を表示する
print("\\n===== COORDIのおすすめ =====")
print("季節：" + season)
print("系統：" + style)
print("好きな色：" + color)
print("トップス：" + top)
print("パンツ：" + bottom)
print("============================")


# ユーザーに好みを入力してもらう
print("COORDIへようこそ！")
season = input("季節（春・夏・秋・冬）：")
style = input("系統（カジュアル・きれいめ・ストリート・シンプル）：")
color = input("好きな色（白・黒・ネイビー・グレー・ベージュ）：")

recommend_outfit(season, style, color)

制作を終えて

COORDIを制作してプログラミングを使えば普段の生活の中にある 服装を選ぶという悩みも便利で楽しい仕組みにできると感じました。 条件分岐を使って入力内容に合わせた提案をすることでプログラムの基本的な仕組みを 学ぶことができました。また機能だけでなく、色や配置、説明にもこだわることが大切だと分かりました。
