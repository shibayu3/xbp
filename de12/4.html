Pythonで作ったくじ引きゲーム

数字を選んで今日の運勢を占ってみよう！

作品紹介

Pythonを使って数字を選ぶと運勢が表示されるくじ引きゲームを作成しました。 1〜500の数字から好きな数字を選び その数字によって大吉・中吉・小吉・吉の 4種類の結果が出る仕組みになっています。

くじ引きゲーム

1〜500の好きな数字を入力してください。

結果はここに表示されます

Pythonで作成したコード

n = int(input("1〜500の数字を選んでね！"))

if n in [1, 5, 45]:
print("🌟大吉🌟")
elif n in [7, 14, 21]:
print("🎊中吉")
elif n in [3, 13, 33]:
print("😊小吉")
else:
print("😋吉")

プログラムの仕組み

このプログラムではif文とelif文、else文を使っています。 入力された数字が指定された数字の中に含まれているかを 判断し、それぞれの条件に合った運勢を表示します。 指定された数字以外が入力された場合は吉と表示されます。

作ってみた感想

Pythonを使ってくじ引きゲームを作ってみて 自分で考えた条件によって結果を変えられることが面白いと感じました。 また少しのコードでもゲームのようなものを作れることが分かり、 プログラミングに興味を持ちました。
